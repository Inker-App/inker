# INKER

INKER keeps your sensitive documents on your Mac and hands your AI chat a copy with the names, SSNs and account numbers replaced by placeholders. Local only, for macOS.

**Drag it into INKER first.** Drop a tax form, a bank statement or a whole folder onto the menu bar icon instead of into the chat. INKER moves it into a private folder outside any app's reach, redacts the sensitive values, and puts a handle like `🐙/w2-2025` on your clipboard. Paste the handle into Claude. Claude reads the redacted copy through INKER and never sees the real values; anything it writes back is filled in again on your Mac.

## Install

Download the latest release from [Releases](https://github.com/Inker-App/inker/releases), open the disk image and drag INKER.app to Applications. It is signed with a Developer ID and notarized. Needs macOS 26.

On first launch INKER asks for a private folder and connects itself to the Claude app. Settings shows whether Claude is connected and offers the same for other chats that speak MCP.

## How it works

- The core is Rust: a vault that maps each real value to a stable token (`[SSN_1]` is the same person everywhere), an index of your documents, and an MCP server on a local socket.
- The menu bar app is Swift. It is the only thing that sees the real values; the MCP server only ever hands out tokens.
- Chat apps and agents talk to INKER over MCP: `list`, `resolve`, `describe` and `write`. Nothing returned to them, logged, or written where they can read it carries a real value.

## Building

The Rust workspace in `core/` builds and tests on Linux and macOS. The Swift shell in `app/` needs a Mac with Xcode 26; see `app/BUILD.md`. `docs/stack-decision.md` records every design decision.

All test documents are synthetic, generated by `samples/`, with values from the IRS's own invalid ranges. A pre-commit hook refuses anything that looks real.
